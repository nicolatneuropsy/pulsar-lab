# Trousse de démarrage : site Entre-temps

## Ce qu'il y a dedans

- `CLAUDE.md` : la mémoire du projet. Claude Code la lit au début de chaque session.
- `PROMPT_DEMARRAGE.md` : le premier message à coller.
- `marque/` : logos en SVG et PNG, favicons, image de partage, polices, jetons de couleur et guide de marque (`MARQUE.md`).
- `reference/` : l'inspiration (animate.bio, gabarit du Laboratoire SAGE) et la structure proposée du site.

## Démarrer

1. Décompresse l'archive là où tu veux garder le site, par exemple dans Documents. Tu obtiens un dossier `entre-temps`.
2. Ouvre l'app Claude et clique sur l'onglet **Code**, en haut au centre.
3. Choisis **Local**, clique sur **Select folder** et sélectionne le dossier `entre-temps`.
4. Dans le sélecteur à côté du bouton d'envoi, choisis le mode **Plan**.
5. Copie le texte de `PROMPT_DEMARRAGE.md` (tout ce qui est sous la ligne) et envoie-le.

## Bon à savoir

- Claude Code est inclus dans l'app de bureau. L'onglet Code ne demande aucune autre installation.
- En mode Plan, Claude Code ne modifie rien. Il propose, tu approuves, puis tu changes de mode pour le laisser travailler.
- macOS peut proposer d'installer les outils de ligne de commande de Xcode au premier usage de git : accepte.
- Tes sessions restent accessibles dans la barre latérale de l'onglet Code.
